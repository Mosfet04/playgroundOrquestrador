## Observações

- `pnpm lint` emite 3 warnings legados; não reprovam o job (só erros). Fora do escopo do item.
- O build e o e2e dependem de rede para `next/font/google` (decisão 0004, até P1-01). O runner do GitHub tem rede; não é bug.
- O passo `pnpm exec playwright install[-deps] chromium` e o cache de `~/.cache/ms-playwright` não são exercitáveis localmente (browser já instalado, sem sudo). Cobertos só pela revisão do YAML.
- Versões das actions (`checkout@v7`, `setup-node@v7`, `pnpm/action-setup@v6`, `cache@v6`) seguem a decisão 0005; a existência das tags não foi verificada sem rede/GitHub.

## Pendências pós-push (verificação do usuário)

1. Abrir um PR de teste e confirmar os dois jobs verdes: `lint, typecheck, test, build` e `test:e2e`. Conferir em especial: resolução das tags major das actions, `pnpm/action-setup@v6` lendo `packageManager`, instalação do Chromium com `--with-deps`, e o cache hit na 2ª execução.
2. Opcional: no mesmo PR de teste, empurrar um commit com erro de lint e outro com teste falhando para ver o PR vermelho.
3. Configurar a proteção de branch da `main` exigindo os checks `lint, typecheck, test, build` e `test:e2e` (configuração do GitHub, a cargo do usuário). Os nomes dos checks vêm do campo `name` dos jobs; mudar o nome quebra a proteção.
