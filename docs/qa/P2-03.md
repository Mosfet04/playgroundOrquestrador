## Observações (sem bug, sem ação)

- Duas formas de evento fazem o run terminar como "interrompido" em vez de seguir: uma `{` que nunca fecha engole os eventos seguintes (fragilidade do parser, fora do que a 0020 decide), e `extra_data.reasoning_steps` que não é lista faz o handler lançar (só o segundo tem teste, sobre o composer). A conversa não trava: composer liberado, texto parcial mantido. Um `tool_name` objeto passaria o zod e quebraria a renderização (cai no `error.tsx`); o contrato diz string e a fonte é o orquestrador.
- `DELETE /sessions/<id>` devolve 200 para um id que não existe, porque o AgentOS responde 204. Esperado.
- O handler de GET e DELETE confia no middleware para a sessão (só o run confere o cookie). O matcher é coberto no e2e, e nenhuma rota escapa dele.
- `%2e%2e` puro nunca chega ao handler (o cliente HTTP e o Next, com 308, normalizam o caminho). `%2F` e `..%2f` chegam e dão 400 `invalid_path`.
