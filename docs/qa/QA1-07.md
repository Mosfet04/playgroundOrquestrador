## Bugs

Nenhum MAJOR ou superior.

Observação (sem severidade, para o dono do texto): a spec contradiz a si mesma. A V8 diz "sem texto 'host'" no toast, mas o texto aprovado de `saveErrorHeaders` ("a rota precisa ser de host confiável") e o de `headersRejected` usam "host". O e2e checa só `terceiro|https?:|ALLOWLIST`, coerente com o texto aprovado. Não bloqueia.

Observação (fora do escopo do item): o orquestrador real valida o nome do header como token HTTP (`_HEADER_NAME`) e o valor contra caracteres de controle. A UI não valida isso no cliente, então um nome com espaço volta 422 `headers` e cai no mesmo erro do grupo. É o comportamento previsto pela spec (o orquestrador não diz qual header).
