## Comportamento documentado (não é bug)

- `/sessions/..%2Fadmin` passa por `isSafePath` e sai literal na URL (o parser WHATWG não decodifica `%2F`), mas o uvicorn decodifica o path inteiro: o app recebe `/sessions/../admin`. O risco fica com ids vindos do usuário; validá-los antes do cliente é critério da P2-03, não deste item.
- Env faltando faz o cliente lançar (mensagem só com o nome da variável); o tratamento no BFF não é testado aqui (P2-03).
- Redirect 3xx para outro host: o Authorization não segue (verificado com o espelho do undici no MSW).
