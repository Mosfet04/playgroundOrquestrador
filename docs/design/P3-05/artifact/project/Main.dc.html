Modelo

Provedor, modelo e como o orquestrador se conecta a ele.

Referência da chave de API

Gravada como env:OPENAI_API_KEY

Só a referência, nunca a chave. Variável de ambiente do servidor do orquestrador, em MAIÚSCULAS e terminando em _API_KEY. Vazio: o agente não define chave própria.

Configuração RAG

Base de conhecimento consultada pelo agente: documento, busca e o modelo que gera os embeddings.

Desligue para pausar o RAG sem perder a configuração.

Embedder

Modelo que transforma o texto em vetores para a busca.

Referência da chave do embedder

Gravada como file:/run/secrets/openai_embed_key

Só a referência, nunca a chave. Caminho absoluto de um arquivo do servidor do orquestrador que guarda a chave. Vazio: o embedder não define chave própria.

Parâmetros do embedder

Nomes aceitos por openai. Valor: número com ponto (0.7), true/false ou texto.

NomeValorTipo
  • número

HTTP (trecho)

Método, rota e headers da requisição.

Headers HTTP

Texto ou Segredo (referência env:, file:). Nome sensível (Authorization, Cookie, …-Key, …-Token) aceita só Segredo. Trocar o modo limpa o valor.

NomeModoValorEstado
  • texto
  • referência

    Gravada como env:LOJA_API_KEY

  • oculto
  • referência

    Gravada como file:/run/secrets/loja_signature

*** é o valor gravado, oculto. Ele é mantido até você substituir, e só se a origem da rota (https://api.loja.example) não mudar.
