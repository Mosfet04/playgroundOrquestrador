# P1-04 — i18n pt-BR e EN (shell e gestão)

- Sem artifact novo. O seletor reaproveita o padrão aprovado do `ThemeSelect` (V-P1-02-3, P1-03): botão ghost no cabeçalho do desktop e linha com rótulo + Select no rodapé do Sheet do celular. Layout: https://claude.ai/artifact/6y3e6H3PbC77qsgNYk5UnL · DS: https://claude.ai/artifact/Cy1ufZWym7KDKjgFFb7Bme · [`design-system.md`](design-system.md) · casca em [P1-03](P1-03.md).
- Decisões fechadas em [0011](../decisions/0011-i18n-next-intl-cookie.md): `next-intl`; idioma em cookie, sem prefixo na URL; trocar = só a server action, que grava o cookie e já devolve a árvore re-renderizada (o `router.refresh()` saiu pelo adendo D-P1-04-5); sem cookie, pt-BR.
- Escopo: casca (cabeçalho, trilha, navegação, Sheet, pular para o conteúdo, `ThemeSelect`), `GettingStarted`, gestão (agents, tools, dashboard, `EntityLoader`, `DeleteConfirmDialog`, forms e toasts), `<html lang>`, `<title>` e formatos. O `/playground` (chat, sessões, hooks, `store.ts`) fica para o P1-04b: até lá, a casca do `/playground` segue o idioma escolhido e o miolo continua como está.

## Objetivo do usuário

Usar o playground inteiro num idioma só (pt-BR ou EN). Trocar de idioma sem perder a tela nem o estado, e ver datas e números no formato desse idioma.

## Fluxo

1. Desktop: no cabeçalho, o botão de idioma fica à esquerda do de tema. Ele abre o menu e a pessoa escolhe o idioma.
2. Celular: no menu (Sheet), a linha "Idioma" fica logo abaixo de "Tema". A pessoa escolhe o idioma no Select.
3. A escolha chama a server action, que grava o cookie e devolve a árvore re-renderizada (sem `router.refresh()`, D-P1-04-5). Os textos, o `lang` e o `<title>` mudam sem recarregar a página. Continuam iguais a rota, os parâmetros da URL, os campos já digitados no form, o Sheet aberto e o foco no seletor.
4. Sem cookie, a página abre em pt-BR, qualquer que seja o idioma do navegador.

Componentes: `Select`, `Button`, `Label` e `Sheet` de `src/components/ui`. Nenhum componente ou token novo, nenhuma dependência além do `next-intl` (0011).

Comportamento:
- O idioma vem do servidor (cookie). Por isso o trigger já renderiza com o valor certo, sem o estado "desabilitado até montar" que o tema tem.
- Durante a troca (transition da server action), o trigger fica com `aria-disabled="true"` e `aria-busy="true"` e o visual de desabilitado (`opacity-50`), mas sem o atributo `disabled`: `disabled` tiraria o foco do seletor e quebraria o V-P1-04-10. Uma 2ª escolha nesse intervalo é ignorada. Não há spinner nem toast.
- Teclado: Tab chega ao trigger; Enter, Espaço ou ↓ abrem o menu; ↑↓ movem; Enter escolhe; Esc fecha sem trocar. O foco volta ao trigger, porque o Radix já faz isso. No celular, a troca não fecha o Sheet.
- Escolher o idioma que já está ativo não faz nada (não chama a server action).
- Foco visível: o foco de V8 do DS (`ring` 2 px + folga 2 px).

## Glossário e tom

Regra: as entidades e os termos técnicos do orquestrador ficam em inglês nos dois idiomas (Team, Tool, Playground, Dashboard, RAG, endpoint, header, embedding, token, prompt). Os substantivos comuns são traduzidos. "Agente" é traduzido porque já está assim na gestão aprovada. Campos legados do contrato (`nome`, `descricao`) não mudam; só os rótulos mudam.

| pt-BR | EN | Nota |
|---|---|---|
| Agente / Agentes | Agent / Agents | masculino: "Novo agente", "Agente não encontrado" |
| Team / Teams | Team / Teams | não usar "time"/"equipe"; "Agente \| Team" do P1-01 |
| Tool / Tools | Tool / Tools | feminino em pt-BR: "Nova tool", "Tool não encontrada", "tool HTTP". **Sai "ferramenta"** (hoje no `GettingStarted`) |
| Playground · Dashboard | Playground · Dashboard | não traduzir |
| Sessão / Sessões | Session / Sessions | "Sessões de agente" / "Agent sessions" |
| Modelo · Provedor | Model · Provider | **sai "Provider" no pt-BR**; "Provedor de embedding" |
| Prompt do sistema · Instruções | System prompt · Instructions | |
| Parâmetros · Headers HTTP · Método HTTP · URL base · Endpoint | Parameters · HTTP headers · HTTP method · Base URL · Endpoint | |
| Ativo / Inativo · Apenas ativos | Active / Inactive · Active only | |
| Excluir · Excluindo… | Delete · Deleting… | **sai "Deletar"** (hoje misturado com "Excluir") |
| Salvar · Salvando… · Cancelar · Editar · Voltar | Save · Saving… · Cancel · Edit · Back | reticências com o caractere `…` |
| Início · Testar · Configurar · Observar | Home · Test · Configure · Observe | grupos da navegação (P1-03) |
| Tema: Claro / Escuro / Sistema · Idioma | Theme: Light / Dark / System · Language | |
| Tokens de entrada / de saída | Input tokens / Output tokens | |

Tom e forma:
- **Imperativo e direto** nos dois idiomas, falando com "você" sem escrever o pronome: "Crie seu primeiro agente" / "Create your first agent". Nada de "por favor", de exclamação nem de emoji em texto novo.
- **Caixa de frase** (só a primeira palavra em maiúscula, além de siglas e nomes): "Informações básicas", "Agentes ativos", "Configuração do modelo" / "Basic information", "Active agents", "Model settings". Isso corrige o Title Case que existe hoje ("Informações Básicas", "Agentes Ativos"). Os grupos da navegação aparecem em caixa alta só por CSS; no catálogo ficam em caixa de frase.
- Erros dizem o que falhou e com o quê: "Não foi possível salvar o agente." / "Couldn't save the agent." O código (`código {n}` / `code {n}`) vai no fim quando existir. Contrações são permitidas no EN.
- O `GettingStarted` é migrado com o conteúdo atual e só ganha glossário e caixa. A reescrita das promessas falsas fica para o P1-05.
- **Texto que vem do BFF não aparece na UI.** Hoje as rotas devolvem `error`/`message` em pt-BR. O toast e o bloco de erro usam o catálogo, escolhido pela ação e pelo status HTTP: 409 = "Já existe um agente com este ID" / "An agent with this ID already exists"; 404 = o "não encontrado" do P1-03; os outros = "Não foi possível {ação} (código {status})". O contrato do BFF não muda.

## Formatos (Intl via `next-intl`, locale `pt-BR` ou `en`)

| Onde | Opções | pt-BR | EN |
|---|---|---|---|
| Totais dos cards e tooltip de tokens | `number` padrão | 1.234.567 | 1,234,567 |
| Rótulo dos gráficos de pizza | `{name}: {number}` | Sessões de agente: 1.204 | Agent sessions: 1,204 |
| Eixo X de "atividade" (chave `YYYY-MM-DD` do BFF) | `dateTime` `{ day: 'numeric', month: 'short', timeZone: 'UTC' }` | 15 de out. | Oct 15 |
| Filtro de período | catálogo | Última hora · Últimas 24 h · Últimos 7/30/90 dias | Last hour · Last 24 h · Last 7/30/90 days |

- `timeZone: 'UTC'` é obrigatório na chave do dia. Sem ele, `2026-10-15` aparece como "14 de out." em UTC−3.
- Some todo `toLocaleString()` sem locale; todo número e toda data na UI passam pelo formatador do idioma.

| | pt-BR | EN |
|---|---|---|
| `lang` | `pt-BR` | `en` |
| template | `%s · Playground do Orquestrador` | `%s · Orchestrator Playground` |
| padrão | Playground do Orquestrador | Orchestrator Playground |
| exemplos | Agentes · Playground do Orquestrador · `{id} · Agentes · …` · Nova tool · … | Agents · Orchestrator Playground · `{id} · Agents · …` · New tool · … |
| `description` | Configure agents, teams e tools do orquestrador e teste no chat. | Configure the orchestrator's agents, teams and tools and test them in chat. |

A `description` atual, que fala do template Agno, sai. O `<title>` de cada rota segue o mapa do P1-03, com o nome da página tirado do catálogo.

## Acessibilidade

- `<html lang>` acompanha o idioma e muda junto com a resposta da server action. Cada opção do seletor tem o `lang` do próprio idioma, para o leitor de tela pronunciar certo.
- Todo `aria-label`, `title`, `placeholder` e `sr-only` do escopo vem do catálogo; os textos EN do P1-03 já estão definidos lá.
- Contraste: o seletor usa os mesmos tokens do botão de tema (`foreground` sobre ghost, hover `accent`), que já passam AA nos dois temas.
- Não precisa de `aria-live` para a troca: o `<title>` e os textos mudam, e o foco fica no seletor.

## Critérios visuais

Screenshots em 1440×900 e 390×844, nos temas claro e escuro. Os dados de `/api/agents*`, `/api/tools*` e `/api/dashboard*` vêm de `page.route`, como no P1-03.

- V-P1-04-1: sem cookie, `document.documentElement.lang` é `pt-BR`; com o cookie EN, é `en`. Depois de trocar pelo seletor, o `lang` muda sem recarregar a página (o E2E confere com `performance.navigation`/sentinela em `window`).
- V-P1-04-2: em 1440 px o cabeçalho mostra, à direita, o botão `PT`/`EN` (36×36, mono) e logo depois o botão de tema, com os dois alinhados e o mesmo hover. Isso vale no claro e no escuro.
- V-P1-04-3: com o menu do seletor aberto, aparecem "Português (Brasil)" e "English", nessa ordem e cada um no próprio idioma, com o check no idioma atual. Isso vale nos dois idiomas da UI.
- V-P1-04-4: em 390 px o cabeçalho é igual ao do P1-03 (menu, título e tema) e não tem seletor de idioma. Com o menu aberto aparece a linha "Idioma"/"Language" abaixo de "Tema"/"Theme", com o mesmo alinhamento e a mesma largura de trigger (`w-44`) e com o nome do idioma inteiro, sem corte. Isso vale nos dois temas.
- V-P1-04-5: com pt-BR, nenhum texto da UI em inglês nas telas do escopo (casca, `/`, `/agents`, `/agents/new`, `/agents/<id>`, `/tools`, `/tools/new`, `/dashboard`, `DeleteConfirmDialog`, toasts). As exceções são os termos do glossário e os dados do orquestrador. Com EN, nenhum texto em português, com as mesmas exceções. Isso inclui `placeholder`, `aria-label` e legendas dos gráficos.
- V-P1-04-6: o glossário vale nas telas. Não aparecem "Deletar", "ferramenta", "Provider" (no pt-BR) nem Title Case nos títulos de seção e de card.
- V-P1-04-7: no `/dashboard` em EN, os totais usam vírgula de milhar (`1,234,567`), e o eixo da atividade mostra `Oct 15`. Em pt-BR aparecem `1.234.567` e `15 de out.`, e o dia é o mesmo da chave do BFF. Os eixos numéricos dos gráficos também passam pelo formatador (`1,200` / `1.200`), e os eixos de contagem (sessões) só mostram inteiros (`allowDecimals={false}`), sem `0.75` nem `0,75`.
- V-P1-04-8: a aba mostra `Agents · Orchestrator Playground` em `/agents` com EN e `Agentes · Playground do Orquestrador` com pt-BR. Em `/agents/<id>` com EN, aparece `<id> · Agents · Orchestrator Playground`.
- V-P1-04-9: o EN não quebra o layout. Em 1440 px os itens e grupos da navegação de 256 px cabem numa linha, sem reticências. A trilha, o título do celular e os rótulos dos forms não se sobrepõem ao seletor nem ao campo. Os botões do form ("Cancel", "Save") e do dialog cabem sem quebra. Nenhuma rota rola na horizontal em 390 e 1440 px.
- V-P1-04-10: trocar o idioma em `/agents/new` com o form preenchido mantém a rota e os valores digitados; só os rótulos mudam. No celular, o Sheet continua aberto e o foco fica no seletor.
- V-P1-04-11: com foco por teclado, o trigger do idioma mostra o contorno `ring` de 2 px com folga de 2 px (V8), no desktop e no Sheet.

## Decisões
